About QuickNotes

QuickNotes is a simple web application that allows users to quickly capture and manage their notes. It was built as part of the Web Foundations course to help developers learn the basics of web development.

How to use QuickNotes

  1. Open QuickNotes and select New Note.
  2. Type the title and write your note in the text area.
  3. Click the "Add Note" button to save your note.
  4. View your notes in the list on the main page.

Features

  • Create and manage notes
  • Simple and intuitive interface
  • Responsive design for all devices
